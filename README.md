# Backend Journey 🚀

A hands-on Django backend development project built while learning Django and Django REST Framework from scratch.

## Features

* Django Models & ORM
* CRUD Operations
* Function-Based Views
* Class-Based Views
* Django Forms
* Django REST Framework APIs
* JWT Authentication
* PostgreSQL Database
* Docker Containerization
* Environment Variable Management
* Production Deployment on Render
